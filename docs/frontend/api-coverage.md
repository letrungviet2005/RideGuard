## 2. Thống kê tỷ lệ bao phủ

- **Tổng số operation theo OpenAPI:** 34 / 34 (100%).
  - API Nghiệp vụ: 31 / 31 (100%).
  - API Kiểm tra sức khỏe hạ tầng: 3 / 3 (100%).
- **Kiểm thử tự động:**
  - 100% operation đã có định nghĩa schema DTO và route đồng bộ tự động (`scripts/generate-api.mjs`).
  - Các kịch bản đã nêu cho các cơ chế cốt lõi (xác thực, single-flight refresh, token memory, idempotency key, CAS version conflict, unbind target, error mapping) đều được kiểm chứng qua 16 bài kiểm thử Node.js độc lập và 8 kịch bản Playwright fixture.
- **Tích hợp Live Backend:**
  - Chưa ghi nhận là đã kiểm chứng trực tiếp với live server do backend và cơ sở dữ liệu cục bộ chưa được kích hoạt trong phiên làm việc hiện tại. Cần chạy smoke tích hợp thật theo runbook trước khi xác nhận vận hành.
